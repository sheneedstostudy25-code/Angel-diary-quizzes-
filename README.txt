ANGEL DIARY QUIZZES
====================

Files:
- index.html
- style.css
- script.js

HOW TO USE
----------
1. Put all 3 files in the same folder.
2. Open index.html in a browser to test.
3. In script.js, replace:
   PASTE_YOUR_MONETAG_DIRECT_LINK_HERE
   with your Monetag Direct Link after your Monetag account/setup is ready.
4. Add your images by filling the "image: """ fields.
   Example:
   image: "images/jungwon.jpg"
5. If you use local images, create an "images" folder beside index.html.

IMPORTANT
---------
- This site is deliberately fan-made/entertainment-oriented.
- It does NOT claim to know private dating preferences or relationships.
- "Ideal type" quizzes are framed as fictional compatibility results.
- Verify current official member rosters and public information before launch,
  especially if a group changes members.
- Do not use official logos or imply affiliation.
- Only use images you have permission to use.
- Test your Monetag Direct Link yourself in a private/incognito browser before
  sending YouTube traffic to it. A direct link is an advertising/monetization
  link and its visitor flow can vary by Monetag format/account.
